# William Stone — Writing Portfolio

A static, responsive writing portfolio for GitHub Pages. No build tools or paid services are needed.

## Publish for free

1. Sign in to https://github.com and create a **public** repository named `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your actual GitHub username).
2. Upload `index.html`, `styles.css`, and the **entire** `assets` and `samples` folders to the repository root. Do not upload only the ZIP; extract it first.
3. Commit the files to the repository's `main` branch.
4. In **Settings → Pages**, under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`, and save.
5. After deployment, visit `https://YOUR-USERNAME.github.io/`. It may take a few minutes to appear.

If you prefer a different repository name, the site can also be published at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/` with GitHub Pages. All links to local assets are relative.

## Edit content

- `index.html`: bio, descriptions, email address, article links.
- `styles.css`: typography, layout, and cobalt/navy colors.
- `assets/`: headshot and article previews.
- `samples/`: two PDF writing samples.

## Notes

- The two Finch Post pieces are local PDF files; the CIEE and Society for Participatory Medicine articles open on their original websites.
- The images for the external article cards are **typographic artwork created for this portfolio**, not original article illustrations.
- The website currently shows four fully linked samples. Add further work after confirming final files/URLs and permission to publish client work.
- The headshot is an AI-edited portrait supplied in the conversation.
- Google Fonts are loaded over the internet; browser fallback fonts are specified if unavailable.
